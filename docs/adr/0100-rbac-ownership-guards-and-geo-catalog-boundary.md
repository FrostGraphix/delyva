# ADR 0100 — Shared RBAC/ownership guards and the geo ↔ catalog boundary

- Status: Accepted
- Date: 2026-11-20

## Context

Phase 1 adds the first protected routes (vendor menu management, customer addresses) and the first
cross-context read (catalog discovery needs geo's zones and ETAs). Several agents add migrations in
parallel.

## Decision

1. **Ownership on top of the shared auth guard.** RBAC reuses the shared `AuthGuard` / `@Roles` /
   `@Principal` (ADR 0200); geo and catalog provide `ACCESS_TOKEN_VERIFIER` from identity's exported
   signer key. This slice adds `OwnershipGuard` + `@OwnsResource('<param>')`, which asks a
   module-local `OwnershipChecker` (`OWNERSHIP_CHECKER`) whether the principal may act on that route
   param; unknown and foreign resources both give 403. Use cases re-check (defence in depth), and
   repositories scope every write by the owner key (`vendor_id`, `user_id`), so a foreign child id
   under an owned parent resolves to 404.
2. **Vendor membership** lives in catalog (`vendor_members`: owner | staff). Staff may only toggle
   availability; owners manage menu, modifiers and hours. Ops/super_admin approve vendors (`go-live`).
3. **geo ↔ catalog.** Catalog never reads geo tables. Geo exports `GeoService`
   (`zonesContaining`, `deliveryEstimate`); catalog declares the `GeoLookup` port it needs.
   `branches.zone_id` is a plain uuid (no cross-context FK) so either context can be extracted.
   Zone containment uses PostGIS `ST_Covers` (GiST index); a pure ray-casting `pointInRing` in
   `geo/domain` documents and unit-tests the same rule.
4. **ETA** sits behind `EtaProvider`: `HaversineEtaProvider` (road factor 1.4, 18 km/h, +5 min
   handling, plus branch prep time) by default; `GoogleDistanceMatrixEtaProvider` behind
   `ETA_PROVIDER=google` + `GOOGLE_MAPS_API_KEY`, falling back to haversine on failure.
5. **Migrations** for this slice use the reserved `0100_` prefix (`drizzle/0100_catalog_geo.sql`),
   generated by drizzle-kit after `0200_pricing` (snapshot chain 0001 → 0200 → 0100, journal ordered by
   `when` so the migrator never skips one), then renamed. Point columns are
   `geometry(Point,4326)` (hand-corrected from drizzle-kit's SRID-less output) and are written via
   `ST_SetSRID(ST_MakePoint(lng, lat), 4326)`.
6. `RouteSpec` gained `put | delete` and `query` (on top of pricing's `patch`/`auth`); OpenAPI emits query params. Context route maps (`GEO_ROUTES`, `CATALOG_ROUTES`) are spread into
   `ROUTES` to limit merge conflicts.

## Consequences

- Any future module gets IDOR protection by providing an `OwnershipChecker` and decorating
  controllers; no per-module JWT code.
- The drizzle-kit snapshot still says `geometry(point)`; a future generate may propose an SRID-only
  diff — review and drop it.
